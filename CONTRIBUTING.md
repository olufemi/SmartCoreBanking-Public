# Contributing to SmartCore Banking

Thank you for your interest in contributing.

## Ways to Contribute

- Report bugs
- Improve documentation
- Add tests
- Propose focused enhancements
- Improve security posture
- Refactor carefully within existing module patterns

## Development Setup

Use a local development environment with Java and Maven. Provide local configuration through environment variables or private local files that are not committed.

## Pull Request Guidelines

- Keep changes focused and explain the reason for the change.
- Include tests when behavior changes.
- Do not include generated build output.
- Do not commit secrets, passwords, tokens, private keys, internal hosts, customer data, or deployment credentials.
- Do not include private or commercial delivery material.

## Coding Standards

- Follow the existing module structure and naming patterns.
- Prefer environment-based configuration.
- Keep public examples generic and safe.
- Avoid introducing customer-specific assumptions.

## Security Contributions

Do not disclose vulnerabilities in public issues. Follow `SECURITY.md` for reporting guidance.
