# Security Policy

## Supported Versions

The public `main` branch is the active open-source development line unless otherwise stated by maintainers.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Report security concerns privately to the project maintainers using the security contact configured for the public repository.

When reporting, include:

- A clear description of the issue
- Affected module or file path
- Steps to reproduce when safe to share
- Potential impact
- Suggested remediation, if known

## Secret Handling

Do not submit secrets, passwords, tokens, private keys, internal hosts, customer data, or deployment credentials in issues, pull requests, examples, tests, or documentation.

## Disclosure

Please allow maintainers reasonable time to investigate and remediate before public disclosure.
