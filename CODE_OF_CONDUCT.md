# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful and productive experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Welcome different levels of experience.
- Focus feedback on the work, not the person.
- Assume good intent while remaining accountable for impact.

## Unacceptable Behavior

- Harassment or abuse
- Discriminatory language or conduct
- Personal attacks
- Publishing private information without permission
- Disruptive or bad-faith participation

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and pull requests that do not align with this Code of Conduct.

## Attribution

This Code of Conduct is adapted from common open-source community standards, including the Contributor Covenant.
