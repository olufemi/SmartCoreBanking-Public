# Smart-Core Admin Portal

Static Community Edition portal shell for SmartCore demo operations.

## Current scope
- community demo admin dashboard
- transaction command center layout
- KPI cards for inflow, outflow, net movement, transaction volume, failed/reversed count, pending approvals
- flow trend bars
- top productCode view
- health snapshot panel
- recent transactions table
- pending approvals panel

## Next build slices
1. login and scoped session model
2. configurable API wiring with demo defaults
3. approvals queue demo integration
4. operators and roles demo screens
5. productCode scoping using demo tenants

## Open locally
Open `index.html` directly in a browser.
