# Community Edition Scope

SmartCore Banking Community Edition is the public open-source distribution of the SmartCore Banking core.

## Included

- modular Java service source code
- service discovery
- API gateway
- general ledger service
- profiling and backoffice domain service
- session and authentication service
- shared utility service
- static Community Edition admin portal shell
- public contribution, security, license, and code of conduct documents
- public-safe documentation

## Not Included

- production credentials
- deployment secrets
- customer-specific material
- live environment configuration
- internal network endpoints
- private support playbooks
- customer onboarding documents
- security operations runbooks
- commercial strategy or pricing material
- enterprise delivery assets
- private integrations

## Enterprise and Commercial Edition Boundary

Enterprise or commercial editions may include private delivery material such as:

- deployment guides
- managed support workflows
- operational playbooks
- customer onboarding assets
- private integrations
- enterprise configuration templates
- implementation support material
- commercial modules or extensions

Those materials are intentionally not part of this public repository.

## Contribution Boundaries

Community contributions should focus on:

- public-safe service improvements
- tests
- documentation
- local development experience
- generic examples
- security hardening
- Community Edition portal improvements

Community contributions must not include:

- secrets or credentials
- customer names or customer-specific data
- internal IP addresses
- production or staging configuration
- private deployment material
- commercial strategy documents
- vendor-specific private integrations

When unsure, keep the contribution generic and open an issue for maintainer guidance.
